# Built HR Policy Assistant Application

An AI-powered Retrieval-Augmented Generation (RAG) assistant designed to search and answer queries from custom uploaded HR Policy PDF documents using Streamlit, FAISS, PyMuPDF, SentenceTransformers, and Groq (`openai/gpt-oss-20b`).
